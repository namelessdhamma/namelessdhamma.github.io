# «Незримый гость» — локальный фонетический ремонт v1.3 (09.10.2026)

**Назначение:** новая версия полной песни на основе предыдущей v1.2, с шестью адресными исправлениями, инициированными замечаниями слушателя. **Статус: ARTISTIC REVIEW ONLY**. Техническое прохождение проверки не означает, что слова уже произносятся правильно или что исполнение стало художественно лучше.

## Замечания слушателя и выполненные операции

| Ошибка услышанная человеком | Цель | Действие в вокальном источнике |
|---|---|---|
| `с` — (долгая пауза) — `тобой` | «с тобой» | перенести настоящую /с/ непосредственно перед «тобой», длина 54 мс вместо нотного слота 278 мс; НЕ ускорять сам согласный |
| `в` — (долгая пауза) — `тишине` | «в тишине» | перенести действительный /в/ перед «тишине», 64 мс; НЕ ускорять |
| `рюди` | «люди» | заменить краткий исходный согласный переход от V3 реальным D1-гайдом, согласовав тембр, без регенерации всего вокала |
| `две тропа` | «две тропы» | заменить второй певческий гласный/его переход оригинальным D1-гайдом |
| `до разлучки` | «до разлуки» | заменить проблемную среднюю артикуляцию исходным D1-гайдом |
| `незабвеннам` | «незабвенным» | заменить финальную реализацию последнего слога D1-гайдом |

Ранее улучшенная пользователем область `видятся` из версии v1.2 строго сохранена. Не внесено других намеренных фонетических изменений.

## Точная методика и пределы

Используется отдельный сухой певческий источник V3, реальная певческая дорожка D1 того же авторского score, и предыдущий полный мастер v1.2. Локальные изменения производятся в сухом голосе. В master вносятся **разницы `новый V3 − исходный V3`**, с исходным исторически приближённым коэффициентом 1.252; это исключает подстановку второго вокалиста поверх запечённой песни. Защита от пиков локальна — только внутри изменённых окон; глобальная громкость или инструментал песни не перенормированы.

Участки вне шести окон сохранены строго идентично предыдущему декодированному PCM v1.2. MP3 при экспорте перекодирован целиком: байтовое тождество вне окон в MP3 нельзя заявлять. Предыдущий принятый M3 и исходные дорожки неизменны.

**Нельзя считать доказанным:** автоматически доказанную человеческую дикцию «люди / тропы / разлуки / незабвенным», естественность всех переходов, художественную приёмку. Данные прослушивания человека являются определяющими. В частности, подстановка D1-фонем с иной голосовой окраской может создать слышимый шов; это кандидат, не чистовик.

Шёпот отдельно. Ограничение «60 минут» не применяется. Певица GG-VFS-F01 на разных песнях не квалифицирована этим тестом.
