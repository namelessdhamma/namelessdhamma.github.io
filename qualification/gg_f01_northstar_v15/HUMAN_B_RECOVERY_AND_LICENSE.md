## Что действительно восстановлено

В библиотеке находится `A7-Mimosa-Dark-Human-Vocal-2026-10-04.zip`. Проверка содержимого обнаружила `04_Human_Vocal_B_Stock.wav` (WAV, SHA256 `04e86eaf120ba8d6b47bed7334bb9ff5568141a42d984bfe0b877ccbc855bc7d`). Это исходник с правильным типом B Stock, совпадающим по именованию с референсом исторического успешного запуска SoulX 4–5 октября. Это **архивная реконструкция**, не криптографическое доказательство совпадения с истёкшим GitHub Actions артефактом. Другой архивный файл `02_Human_Vocal_B_EZV2.wav` SHA256 `ef405c0cf82cacb0a147232ace38a6a02ab7359d088a7d361c03bde64ab3b5e0` отличается и не может молча заменить B Stock.

Задокументированный старый SoulX-запуск `.github/workflows/gg-soulx-phonetic-repair.yml` использовал prompt-pack run `37194439702`, искал файл с шаблоном `*B*STOCK*.wav`, а иначе выбирал последний по сортировке WAV. Без полного оригинального zip нельзя доказать конкретный байтовый prompt только по шаблону: `Stock`/`STOCK` различаются по регистру на Linux. Продакшн должен хранить прямой SHA256, не использовать сортировочный fallback.

## Лицензия, которую нельзя игнорировать

Официальная страница Mimosa запрещает использовать исходные сэмплы/голосовой материал как вход для ИИ. Исторический B Stock сохраняется **только для архивного изучения и сравнения**, запрещён как ввод в новую SoulX/RVC/другую ИИ-модель до документального разрешения: https://utaufrance.com/en/voicebank/mimosa/ . Аудио не копировать в публичный репозиторий, не включать в новые дистрибутивы.

Awata Weak в официальном README разрешает коммерческое использование вокального банка: https://github.com/hhskt/Awata_Weak . Новая проверка на основе оригинального D1-гайда и prompt из Awata в отдельной ветке может быть квалифицирована как эксперимент, без автоматического утверждения коммерческой пригодности сторонних сервисов.

## Что проверяется в v1.5

Один bounded GitHub Action `gg-f01-v15-clean-guide-soulx-awata-svc.yml`: источник — оригинальный чистый D1 guide с проверкой SHA; prompt — свежий Awata v14 rubato (не Mimosa); преобразователь — SoulX SVC; результаты сохраняются только как исследовательский WAV, с независимым Whisper-small и строгим сопоставлением текста «Мы встретились с тобой, как люди видятся во сне». Это проверка гипотезы, а не завершение North Star.

Двойной порог приёмки: (1) текст + фонетика отдельных слогов на сухом вокале, (2) музыкальность, ясность «мы», связное пропетое «встретились», безусловное «видятся», выразительность и та же певица, что в ранее принятом материале. ASR CER=0 не эквивалентно художественной и фонетической приёмке. При несоответствии источник отклонить. Не чинить недостатки громкостью, шёпотом, сглаживающим фильтром или добавлением второго голоса.

## Что остаётся после пробного результата

Если фраза прозвучит естественно, проверить повторяемость голосового ID на другой русской мелодии (не только той же строке), отладить права и инструментальное сведение через настоящий отдельно исходный instrumental REAL V2. Если не прозвучит, не повторять слепой перебор конфигураций, а перейти к лицензированному источнику с явной фонемной моделью либо другому генеративному композитору.

Нет ни обещания «60 минут на песню», ни включённого в этот проход шёпота. Принятый M3/V3/V3.1 остаётся неизменённым. Работа — ветка экспериментов, не каноническая публикация.
