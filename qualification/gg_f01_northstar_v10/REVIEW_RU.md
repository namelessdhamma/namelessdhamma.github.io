# GG F01 — первая строка «Незримого гостя»: V3 SOURCE RESCUE v1.0

**Статус:** реальная новая художественная проба на прослушивание, **не принята**. Предыдущая v0.8 — REJECT по отзывам пользователя: почти отсутствующее «мы», механическое/проговорённое «встретились», «видится» вместо «видятся».

## Что именно изменено

Не микшерный gain fix и не очередной RVC. Заменён **весь источник певческого исполнения первой строки**: вместо проблемного Z10 взят оригинальный V3_VOCAL_REPAIRED, использовавшийся в ранее принятом M3. Инструментал взят **из отдельно сохранённого REAL_V2**, а не из мастера с уже впечённым вокалом. Исполнитель не менялся; альтернативный певец, фрагментарные сэмплы, двойной голос, повторный RVC и шёпот не использовались.

- Оригинальный V3, сухой: `output/V10_V3_ORIGINAL_SINGER_DRY.wav`.
- Главный кандидат с музыкой: `output/V10_V3_ORIGINAL_SOURCE_CLEAN_STEMS.mp3`.
- Принятый M3 исходный мастер, тот же фрагмент: `output/V10_USER_ACCEPTED_M3_MASTER_REFERENCE.mp3`.
- Отклонённый источник Z10, контроль: `output/V10_PRIOR_REJECTED_Z10_SOURCE_REFERENCE.mp3`.
- Сравнение отдельно слова «видятся» в более медленном темпе: `output/V10_V3_VIDYATSYA_ISOLATED_SLOW.mp3`.

Все файлы — [7.5,15.35] секунды исходной песни с абсолютным сохранением исходной мелодии; следующая строка отрезана. Записи декодированы в 48 кГц, непрерывная оригинальная фраза, обработано общее покрытие, без пословного разрушения артикуляции.

## Доказательства и ограничения

Исходники защищены SHA-256; 9 локальных проверок прошли. V3 имеет существенно более слышимый вход слова «мы», чем Z10, и «встретились» сильнее на 9.49 дБ (RMS). Для «видятся» V3 немного сильнее по уровню и отличается от Z10 формантной артикуляцией; **фактическое произношение «видятся» ещё не утверждено**.

`phoneme_audit.py` выводит F0, F1, F2 около «видятся» из Praat/Burg. Это *exploratory*, не автоматическое распознавание слова или оценка его правильности. Лингвистический контекст часто заставляет ASR написать «видятся», даже когда слушатель слышит «видится». У певицы допустима более открытая реализация безударного «я» для ясности.

Оценённые ранее коэффициенты восстановления сведения M3 (voice~1.252, instrumental~1.057) **не исторические настройки DAW**. Новая версия не является точной копией M3; исходный M3 приложен для слухового сравнения. Для предотвращения клиппинга введено только общее масштабирование, а не искажающая автоматизация фраз.

## Критерий решения

Принимаем по слуху только если все слова слышны, «встретились» поётся одной связной музыкальной фразой, «видятся» воспринимается как нужная форма, тембр певицы согласуется с остальной песней. Если даже V3 неверен, требуется **новый пофразовый синтез из проверенной нотно-фонемной партитуры D1_FULL_V3** с управляемым вокальным источником; повторный gain/RVC/ASR не исправит дефект исполнения. Шёпот отложен по указанию пользователя.

Повторяемая певица на других песнях ещё не квалифицирована. Принятый полный мастер не изменялся. Это исследовательский дочерний Human Vocal под действующим Studio current, не публикация песни и не принятие нового True Sound.
