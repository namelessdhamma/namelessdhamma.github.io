# GG-VFS-F01 — прослушивание вступления, v0.8 (9 октября 2026)

**Цель:** художественная оценка первой строки «Мы встретились с тобой, как люди видятся во сне». Шёпот отложен по решению пользователя и не является условием принятия этой версии.

## Основное прослушивание

- `results/CANDIDATE_EXPRESSIVE_F01_WITH_MUSIC.mp3` — предлагаемое вступление: 10,68 с от 5,8 с исходной песни до 16,45 с.
- `results/ORIGINAL_Z10_REFERENCE_WITH_MUSIC.mp3` — неизменённый исходный певец с тем же инструменталом и общим уровнем; контроль сравнения.
- `results/USER_ACCEPTED_V3_SOURCE_REFERENCE_WITH_MUSIC.mp3` — источник более ранней принятой V3/M3 основы, пересведённый с независимой музыкой.
- `results/CANDIDATE_EXPRESSIVE_F01_DRY.wav` — сухой вокал предлагаемого варианта.

## Процесс

Источник — исторически записанный единый Z10-вокал (SHA-256 `ee7261383a99f7ea055eb0ac0dcd1ab73472c18882fdf7004df423e65dfc8dfd`). Текст первой строки был точно распознан русским Whisper-small для исходника и прошлых неброских динамических вариантов. Для v0.8 проводится музыкальная, но не фонетическая, редакция: деликатные смысловые динамические акценты (от +0,3 до +1,3 dB), индивидуальные микс-понижения инструментала (~0,3–0,4 dB), без изменения высоты, времени, фонем, голосовой идентичности и без второго RVC-прохода. Вступление не притворяется шёпотом.

Использованы подлинная партитура `D1_FULL_V3` (15 нот первой строки, музыкальные ударения) и самостоятельная аранжировка REAL V2 (не уже вокальный мастер). Базовые относительные коэффициенты смешивания ~1,2518 (вокал) и ~1,0567 (инструментал) — обратные оценки по V3/M3, НЕ оригинальные настройки микшера. В финале применяется общая компенсация headroom, true peak < -1.1 dBFS; никаких hard-clip/добавочных певиц.

## Воспроизведение

Операции полностью локальны: Python 3.11+, numpy, scipy, soundfile и FFmpeg в PATH. Разархивировать и выполнить `python build_portable.py`. Это заново пересоздаёт те же **исходные аудиофайлы WAV**, тогда как повторная MP3-кодировка может зависеть от FFmpeg/libmp3lame.

Скрипт сверяет SHA-256 всех исходных MP3, действительную мелодию партитуры и контрольные операции. Все файлы исходной песни оставлены без изменений. Никакой сетевой, GPU, ASR- или платной операции для воспроизведения этого конкретного результата не требуется.

## Текущее состояние

**Готово для прослушивания пользователем, не принято художественно.** Прошло 24 технических теста. Звуковая версия для прослушивания реально существует, но это не доказательство универсального генератора певицы. Повторяемый вокал на новой песне и права на некоторые исторические голосовые данные остаются незакрытыми. Техники Mimosa/Sveta остаются исследовательскими до выяснения прав и успешного квалификационного испытания.

**Следующее решение:** оценить предложенное вступление по естественному пению, страсти/эмоциональности, произношению, связности фразы и совпадению голоса с остальной песней. Если принят, заменить только одно вокальное окно на независимых дорожках в версии-кандидате, не изменяя существующий мастер до отдельного разрешения.
