## Новая инструментальная верификация M3

Поскольку сохранены ВСЕ ТРИ оригинальные MP3, была выполнена независимая оценка их композиционного смешивания. По моно-сигналу 12 kHz после коррекции временного лага +60 отсчётов (=5ms) произведён линейный least-squares fit:

- `master(t+0.005s) ≈ 1.252 × vocal_V3(t) + 1.057 × instrumental_V2(t)` на интервале 12–55s;
- `R²=0.9873` на обучающем окне;
- `R²=0.9822–0.9873` на шести контрольных окнах 12–238s, параметры по окнам в `results/GOLDEN_TECHNICAL_AUDIT.json`.

Это обратная реконструкция по MP3, **не точное восстановление первоначальных настроек DAW**. Остаток зависит от компрессии, эквализации, декодирования и возможных нелинейных эффектов. Сравнение первых 11 секунд выбранного окна содержит сначала оригинальный мастер, затем оценочное восстановление: `results/M3_GOLDEN_vs_ESTIMATED_RECONSTRUCTION.mp3`. Оно **не должно заменять** принятый мастер.

## Повторное воспроизведение C/D

`replay/GG_NORTHSTAR_SUCCESS_CD_INDEPENDENT_QA_20261009.zip` — **новый рендер** исторического SoulX source через Applio/Awata C/D (GitHub Actions run 37893283543; выполнение и независимая ASR прошли).

- Original full sentence: «Я говорил не с ним, а с тем, кто долго стоял у окна и ждал» — 0 ошибок при автоматическом распознавании;
- C: тот же текст точно, CER 0;
- D: «... кто долго стоя у окна ...», отсутствует финальная «л» слова «стоял»; CER ~0.0179, поэтому D **не проходит строгий лексический gate именно в этом новом рендере**;
- повторные C/D не побитово идентичны историческим, Pearson-корреляция ~0.946 / ~0.948. Не заявлять детерминированную побитовую воспроизводимость при этом backend.

Ни один результат ASR не доказывает выразительность, настоящий шёпот или субъективную музыкальную приёмку.

## Команды

Работает на Python 3.11+, FFmpeg, numpy, scipy, soundfile. Зависимости `pip install numpy scipy soundfile`.

```bash
python qualify_golden_route.py
python decision_map.py --song-selection V3_1
python -m unittest discover -p 'test_vocal_golden_v04.py' -v
```

Запуск повторно проверяет все исходники, вычисляет SHA-256, источник/мастер-совмещение, сохранённые ASR выводы, критическую потерю слова у D и выдаёт машинный отчёт; никогда не изменяет принятые MP3.

**19/19 локальных тестов пройдены**, в том числе защита от ложной фразы с поддельным полем `exact=true`, несанкционированного V3.1 asset ID и повышения V4/W/Z10 до художественного PASS.
