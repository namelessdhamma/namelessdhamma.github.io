# ND Telegram Publisher — Vercel Reserve

Third independent publishing contour for @NamelessDhamma.

Route: GPT -> Vercel Function -> Telegram Bot API.

Required production environment variables:
- ND_TELEGRAM_PUBLISHER_BOT_TOKEN
- ND_TELEGRAM_CHANNEL_ID=@NamelessDhamma
- ND_TELEGRAM_MCP_PATH_TOKEN
- ND_TELEGRAM_WRITES_ENABLED=true

Source is independent from Railway and Render runtimes.
